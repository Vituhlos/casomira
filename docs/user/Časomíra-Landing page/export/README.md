# Časomíra — produkční assety loga (vyvážená varianta)

## Specifikace
- Ramena (light verze): #18181b · Ramena (dark verze): #FFFFFF
- Apex bod: #006FEE — nikdy nepřebarvovat, vždy sedí v mezeře mezi rameny
- Písmo nápisu: Figtree SemiBold 600, letter-spacing −1,5 % (licence SIL OFL, viz Figtree-OFL.txt)
- Zarovnání lockupu: vrch ramen = cap-height, spodek bodu = účaří; ikona 1,346× cap-height, mezera 0,28× velikosti textu
