# Dev issues / backlog

Tahle složka slouží jako repozitářový backlog pro větší úkoly, které ještě nejsou implementované. Je to praktická náhrada za GitHub Issues ve chvíli, kdy chceme zadání držet přímo v repu a verzovat ho spolu s kódem.

Doporučený formát souboru:

```text
NNN-nazev-ukolu.md
```

Každý issue soubor by měl ideálně obsahovat:

- krátký cíl,
- proč to řešíme,
- rozsah MVP,
- co do MVP nepatří,
- technický návrh,
- akceptační kritéria,
- otevřené otázky.
